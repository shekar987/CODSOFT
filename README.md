# CodSoft Java internship projects

Five Java projects I built during my CodSoft internship (Jan–Jun 2022).

| Project | What it is |
| --- | --- |
| [`SCRS2`](SCRS2/) | A course registration system with layered design (entity, service, persistence, presentation), a JDBC persistence layer behind a `DatabaseManager`, and validation that blocks duplicate enrolments |
| [`QuizApplication`](QuizApplication/) | A Swing quiz with a timer for each question, scoring and replay |
| [`Atm_interface`](Atm_interface/) | A menu-driven ATM simulation: withdraw, deposit, check balance |
| [`Student_Grade_Calculator`](Student_Grade_Calculator/) | Totals, average percentage and a grade from subject marks |
| [`guess_game`](guess_game/) | Guess a random number between 1 and 100 in limited attempts |

Each folder is an IntelliJ project with a `Description.text` explaining it. Front-end work from the same internship is in [CODSOFT_webdevelopment](https://github.com/shekar987/CODSOFT_webdevelopment).
